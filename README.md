# Каталог русификаторов

Сайт из двух файлов: `index.html` (страница) и `games.js` (список игр и настройки).
Менять нужно только `games.js`.

## Как добавить или обновить игру
1. Выложи пост с архивом в Telegram-канал.
2. Нажми на пост правой кнопкой → «Копировать ссылку». Получится `https://t.me/канал/15`.
3. В `games.js` у этой игры впиши номер поста: `tg: "15"` (или всю ссылку целиком).
4. Новая версия: поменяй `version`, `date`, `size` и `tg` на новый пост.
5. Новая игра: скопируй блок `{ title: ... },` и поменяй поля.

`status`: `"ready"` — готово, `"beta"` — бета, `"soon"` — скоро.
Если `tg` пустой, на карточке написано «Скоро в канале».

Канал должен быть **публичным**, иначе ссылки не откроются у тех, кто не подписан.

## Обложки
Сейчас обложки берутся по ссылкам с Википедии (поле `coverUrl` в `games.js`).
Чтобы поставить свою картинку, положи её в папку `covers/` с именем из названия игры:
маленькие латинские буквы, всё остальное заменить на «-», расширение `.jpg`.
Например: `covers/stella-glow.jpg`, `covers/fire-emblem-fortune-s-weave.jpg`, `covers/pokemon-pokopia.jpg`.
Своя картинка важнее ссылки. Если нет ни того, ни другого, рисуется цветная заглушка с названием.
Лучше всего смотрятся вертикальные картинки 3:4. Квадратные тоже подойдут: по бокам будет размытый фон.

## Как выложить на GitHub Pages (один раз)
1. Зарегистрируйся на github.com.
2. Справа вверху «+» → «New repository». Имя, например, `ru-patches`, тип **Public** → «Create repository».
3. На странице репозитория: «uploading an existing file» → перетащи `index.html`, `games.js` (и папку `covers`, если положил туда картинки) → «Commit changes».
4. «Settings» → «Pages» → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → «Save».
5. Через 1–2 минуты сайт будет по адресу `https://<твой-ник>.github.io/ru-patches/`.

Обновлять: открыть `games.js` на GitHub → значок карандаша → поправить → «Commit changes».
Через минуту сайт обновится сам.

## Посмотреть локально
Открой `index.html` двойным щелчком в браузере.
